Confidence, not just a score

Process

From paper to reviewed result in four steps.

1

Upload the exam batch

Drop in a single scanned PDF covering an entire class, or individual student files. Batches split automatically by page count per student.

2

Extraction runs page by page

Handwritten text, equations, and student identity fields are extracted and matched to the correct question, regardless of physical page order.

3

Rubric grading with reasoning

Each answer is scored criterion by criterion against the rubric you built, with written reasoning attached to the result.

4

Instructor review and resolution

Review flags and grading disagreements stay visible. The instructor can approve or override a result and record the human label for evaluation.

Prototype boundary

Clear about what is protected today—and what comes next.

MISRA currently runs as a trusted local thesis prototype. Authentication and production deployment controls remain explicit future work.

Trusted local access

The current workspace is intended for a controlled development machine, not an internet-facing deployment.

Private repository hygiene

Uploaded papers and local environment secrets are excluded from Git; only an empty upload placeholder is versioned.

Every identity match is reviewable

Uncertain OCR of a student's name or ID is never auto-confirmed. A person resolves it.

Grading lineage

Grading runs retain their mode, model, prompt, rubric version, score, confidence, and response for later comparison.

FAQ

Common questions

Is authentication available?

Not yet. The current build is a local instructor prototype. Real account authentication and institution-level authorization are planned before any public deployment.

What languages does grading support?

Arabic, English, and mixed Arabic/English answers, including STEM notation rendered as LaTeX.

Can an instructor override a grade?

Yes. An instructor can approve or override an AI result, add review notes, and preserve the human decision as an evaluation label.

Where is student data stored?

Papers are stored on the local application machine and grading records are stored in MariaDB. Selected page content is sent to Gemini for OCR and grading, so the prototype should use only approved test data.
